RADIUS & Policy

Site / Package / NAS เป็นข้อมูลตัวอย่างและ Draft แยกใน Browser · ยังไม่เชื่อม RADIUS Manager จริง · การแก้ไข Site / Package ในหน้านี้ยังไม่เปลี่ยน Portal Configuration, Dashboard หรือระบบจริง

เพิ่ม Site

Site Draft อยู่เฉพาะ Browser · ยังไม่เปลี่ยน Site ที่กำหนดสิทธิ์ผู้ใช้หรือ Portal Configuration

Allow Package (เลือก Package ที่อนุญาตสำหรับ Site นี้)

รายการที่เลือกใหม่ใช้ User Prefix จาก Package และ Limit = ไม่กำหนด; ค่าที่มีอยู่จะถูกเก็บไว้

Allow Package

Allow Package ใน Site Draft นี้ · ยังไม่เชื่อม RADIUS Manager

กดชื่อ Package เพื่อดูรายละเอียด Policy, ความเร็ว และเวลาการใช้งาน · Limit ที่เป็น — หมายถึงไม่มีข้อมูล

เพิ่ม Package

Package Draft สำหรับทดลองเท่านั้น · ยังไม่อัปเดต RADIUS Manager หรือ Portal Configuration

1st Login: กำหนดจำนวน Days นับจากการเข้าสู่ระบบครั้งแรก (ค่าเริ่มต้นในฟอร์ม 30 วัน) · Specified Date: ระบุวันที่หมดอายุ · Unlimited: ไม่กำหนดวันหมดอายุ · เป็นการตั้งค่า Draft เท่านั้น ยังไม่บังคับใช้งานบน RADIUS จริง

Package เดิมใช้ข้อมูล Type / Expiration แบบข้อความ กรุณาเลือกค่าจากรายการก่อนบันทึก (ค่าที่มีอยู่ยังคงเดิมจนกว่าจะบันทึก)

จัดการ NAS

NAS Draft สำหรับทดลอง UI แบบ Offline เท่านั้น · ไม่ส่งค่าไปยัง RADIUS จริง · ใช้ Secret จำลองเท่านั้น เพราะข้อมูล Draft อยู่ใน localStorage ของ Browser และไม่ได้เข้ารหัส · ใช้เมนูนี้ด้วยบัญชี System Admin ในต้นแบบ
